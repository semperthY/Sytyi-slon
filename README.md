# 🐘 СЫТЫЙ СЛОНЪ

Современный сайт кафе, разработанный на Next.js с использованием React, TypeScript и Tailwind CSS.

---

# Технологии

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git
- GitHub
- Vercel
- Termux

---

# Архитектура проекта

```
src/

app/          Страницы

components/   Компоненты интерфейса

config/       Общие настройки сайта

data/         Контент сайта

public/       Изображения
```

---

# Структура данных

config/

- site.ts
- navigation.ts

data/

- menu.ts
- contacts.ts
- footer.ts

# Рабочее окружение

Используется Termux.

Основные команды:

```bash
cafe
```

Переход в проект.

```bash
helpme
```

Справка.

```bash
check
```

Проверка проекта.

```bash
deploy "Комментарий"
```

Коммит и публикация.
